# RepoPilot

> Open-source autonomous software engineering agent.

RepoPilot is a production-oriented AI software engineering platform that can understand a software repository, analyze issues, retrieve relevant code, plan changes, implement fixes, execute tests in an isolated sandbox, debug failures, review changes, and create pull requests with human approval.
